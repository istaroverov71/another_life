# Контент «Другой жизни»

Здесь лежит всё, из чего собирается жизнь героя. Бот ничего не генерирует сам: он только выбирает готовые тексты по правилам. Концепция проекта описана в Google-документе «Другая жизнь — концепция».

## Что где лежит

- `world/regions.json` — 83 региона России: число родившихся по годам, города и посёлки с населением, продолжительность жизни, доля национальных имён. Собирается скриптом `tools/build_world.py` из данных в `research/data/`, руками не правится.
- `world/names.json` — имена: топ-100 каждого года рождения с частотами и национальные пулы. Тоже собирается скриптом.

Откуда данные и почему так — в `research/russia.md`. Там же правила тона: как писать про Россию без «клюквы» и как обходить политику и религию. Их нужно прочитать до того, как писать новые события.
- `world/start.json` — стартовые условия: достаток семьи, родители, брат или сестра, характер.
- `world/careers.json` — 24 профессии и 200+ компаний по годам и городам. Собирается скриптом `tools/build_careers.py`. Иностранные компании доступны только до ухода из России (`left`), дальше на их месте преемник (`successor`): McDonald's → «Вкусно — и точка», KPMG → Kept, Starbucks → Stars Coffee и так далее. Переименования (`renamed`): Сбербанк → «Сбер», Mail.ru Group → VK, «Тинькофф» → Т-Банк.
- `variants/*.json` — другие формулировки уже существующих событий и развилок. Бот выбирает вариант случайно, поэтому одно и то же событие в разных жизнях звучит по-разному.
- `events/*.json` — события жизни по периодам (плюс `career` — работа и карьера, `extra` — новые события по всей жизни): `childhood` (0–17), `youth` (18–22), `adult` (23–40), `middle` (41–60), `elder` (61+), плюс слои, которые идут через всю жизнь: `era` (события эпохи), `media` и `foreign` (что смотрели и слушали), `abroad` (жизнь после переезда).
- `forks/*.json` — развилки с кнопками: `childhood`, `life` (вся взрослая жизнь), `era` (осень 2022-го), `abroad` (вернуться домой).
- `endings/deaths.json` — как заканчивается жизнь: коротко, спокойно, без натурализма.
- `duo/meetings.json` — сценарии встречи героев в режиме «вдвоём».

## Как устроено событие

```json
{ "id": "ch_first_grade", "must": true, "months": [9], "age": [7, 7], "time": "any",
  "text": "Первое сентября. Букет гладиолусов больше, чем {name}. Первый класс.",
  "if": { "city": ["capital"] }, "fx": { "happy": 3, "flags": ["has_friend"] } }
```

- `id` — уникальное имя события.
- `text` — основной текст; `texts` — все варианты текста (первый совпадает с `text`). Варианты можно класть и в отдельный файл `variants/*.json`: `"texts": { "id события": ["вариант", ...] }`, `"results": { "id развилки#номер кнопки": ["вариант итога", ...] }`.
- `age` — в каком возрасте может случиться (от и до, включительно).
- `time` — время суток: `m` утро (9–12), `d` день (12–17), `e` вечер (17–20), `any` — любое. Это мягкое правило: событие своего времени выпадает чаще.
- `months` — если событие сезонное (лагерь летом, Первое сентября), в какие месяцы оно возможно.
- `must` — обязательное событие: если подходит по условиям, выпадает первым.
- `if` — условия: `years` (календарные годы), `city` (тип города), `wealth`, `parents`, `sib`, `trait`, `gender`, `flags` (что уже случилось), `not` (чего не должно было случиться).
- `fx` — последствия: изменение скрытых параметров (`health`, `happy`, `social`, `study`, `money`), новые флаги (`flags`), снятие флагов (`unflags`), а также `spouse: "new"` (появился любимый человек), `child: true` (родился ребёнок, имя — из моды года рождения), `divorce`, `breakup`, `widowed`, `move` (`big`, `capital`, `region_center`, `sea`, `abroad`, `home`).
- Дополнительные условия `if`: `any` (хотя бы один флаг), `kids_min`, `kids_max`, `kid_age` (возраст старшего ребёнка), `health_min/max`, `money_min/max`, `region_in`, `city_name`, `dad_due`, `mom_due`, `spouse_due` (пришло время ухода родителей или супруга), `min_years_abroad`.
- `span: true` — событие на несколько тихих лет сразу, для глубокой старости.
- Работа: `fx.job` — устроиться (`"it"`, список профессий, `"auto"` — по образованию и распространённости, `"same"` — та же профессия, новое место), `fx.company` — компания ушла или переименовалась. Условия: `field` / `not_field` (профессия), `job_years` (сколько лет на этом месте), `company` (`successor`, `closed`, `renamed`). `render_after: true` — текст пишется уже после последствий (нужно, когда событие меняет работу).
- Развилка с `pick: 3` показывает только три случайные кнопки из подходящих (с учётом того, насколько профессия распространена в этот год); кнопка с `always: true` показывается всегда.
- Событие, где упоминается супруг, ребёнок или брат, выпадает только тем, у кого он есть: это движок проверяет сам.

## Жизнь целиком

- Год рождения — любой с 1980 по 2020, игрок выбирает его перед каждой жизнью.
- 21 день максимум, план по возрастам — `LIFE_PLAN` в `sim/engine.js`. У каждого года есть сообщение; в старости тихие годы объединяются в одно сообщение с диапазоном.
- Возраст смерти — по средней продолжительности жизни в регионе для пола героя (Росстат) с разбросом, не раньше 30 лет. Здоровье сдвигает его: каждые 8 пунктов здоровья выше или ниже 65 — плюс или минус год.
- Родители уходят, когда герою примерно 44–59 (отец) и 50–65 (мать), супруг — по своей статистике.
- В конце — итог жизни: города, семья, дело жизни и до десяти главных развилок.

## Основные флаги

Учёба: `uni`, `college`, `army`, `after_army`, `graduated`, `moved`, `stayed_home`. Работа: `employed`, `job_<профессия>` (например `job_it`), а также общие `office_job`, `it_job`, `budget_job`, `worker`, `own_business`, `vahta`, `retired`. Отношения: `dating`, `together`, `engaged`, `married`, `no_stamp`, `divorced`, `ever_divorced`, `widowed`, `has_kids`, `kid_left`, `kid_married`, `grandkids`. Жильё и быт: `renting`, `mortgage`, `own_flat`, `dacha`, `car`, `license`, `cat`. Семья: `dad_died`, `mom_died`. Заграница: `abroad`, `settled_abroad`, `returned`.

## Переменные в тексте

- `{name}` — имя героя. **Только в именительном падеже**: склонять имена автоматически ненадёжно, поэтому фразы строим так, чтобы падеж не понадобился.
- `{сделал|сделала}` — форма для мужского и женского рода героя. Можно и коротко: `{поехал|поехала}`.
- `{s:родился|родилась}` — то же для брата или сестры, `{fr:позвал|позвала}` — для лучшего друга или подруги.
- `{sib}`, `{friend}`, `{crush}` — имя брата или сестры, лучшего друга, первой любви.
- `{spouse}`, `{sp:пришёл|пришла}` — любимый человек героя; `{ex}` — бывший; `{kid1}`, `{kid2}`, `{k1:сын|дочь}` — дети; `{partner}`, `{p:…}` — герой друга в режиме «вдвоём».
- `{job}` — должность героя («тестировщик», «медбрат|медсестра»), `{at_company}` — где он работает («в «Сбере»», «на АвтоВАЗе»), `{company}` — название, `{company_old}` — прежнее название после ухода или переименования. Пишем вместе: «{name} — {job} {at_company}».
- `{in}` — «в Казани», «в городе Глазов», «в посёлке Шушенское», «в деревне в Вологодской области». Склонённые формы есть только у городов от 250 тысяч, остальные пишутся через «в городе». `{to}` — «в Казань» (только для городов, куда герой может переехать). `{city}` — название.
- `{olymp}`, `{first_money}` и другие — случайная строка из списка `fills` в конце файла событий.

## Как проверить

```
node sim/simulate.js --check 5000
```
Проживает 5000 жизней и ищет ошибки: незаполненные переменные, нарушенный порядок дат, события, которые не выпадают ни разу.

```
node sim/simulate.js --year 1995 --seed 42
```
Собирает одну жизнь в `samples/`, чтобы прочитать её глазами пользователя.
